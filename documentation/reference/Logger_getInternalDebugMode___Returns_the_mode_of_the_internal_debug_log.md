# Logger_getInternalDebugMode - Returns the mode of the internal debug log

Gets the current mode of the internal debug log and returns a value of type **LOG4RPG_debugMode_t**.

## Syntax

**Logger_getInternalDebugMode**(***i_hLogger***)

The syntax of **Logger_getInternalDebugMode**-procedure uses the following parameters:

| Parameter            | Description                                                   |
|:---------------------|:--------------------------------------------------------------|
| ***i_hLogger***      | Required. Handle of the logger of type **LOG4RPG_hLogger_t**. |

## Return Value

| Name                 | Description                                                     |
|:---------------------|-----------------------------------------------------------------|
| ***debugMode***      | Mode of the internal debug lof of type **LOG4RPG_debugMode_t**. |

## Comments

none
