# Configurator_loadDefaultConfiguration - Load default configuration

Loads the default configuration data and returns a value of type **BOOL**.

## Syntax

**Configurator_loadDefaultConfiguration**()

The syntax of **Configurator_loadDefaultConfiguration**-procedure uses the following parameters:

| Parameter            | Description            |
|:---------------------|:-----------------------|
| none                 |                        |

## Return Value

| Name                 | Description                                               |
|:---------------------|-----------------------------------------------------------|
| ***isConfigured***   | Returns `*ON` on success, otherwise `*OFF`. |
