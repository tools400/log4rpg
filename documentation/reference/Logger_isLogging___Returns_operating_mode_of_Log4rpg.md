# Logger_isLogging - Returns operating mode of Log4rpg

Returns the current operating mode of Log4rpg and returns a value of type **BOOL**.

## Syntax

**Logger_isLogging**()

The syntax of **Logger_isLogging**-procedure uses the following parameters:

| Parameter            | Description                                               |
|:---------------------|:----------------------------------------------------------|
| none                 |                                                           |

## Return Value

| Name                 | Description                                               |
|:---------------------|-----------------------------------------------------------|
| ***isEnabled***      | Current operating mode of Log4rpg of type **BOOL**.       |

## Comments

none

## Module

LOG4RPG01
