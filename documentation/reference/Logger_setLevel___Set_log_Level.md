# Logger_setLevel - Set log level

Specifies the log level for a given logger.

## Syntax

**Logger_setLevel**(***i_hLogger***, ***i_level***)

The syntax of **Logger_setLevel**-procedure uses the following parameters:

| Parameter            | Description                                                                                                                                             |
|:---------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
| ***i_hLogger***      | Required. Handle of the logger of type **LOG4RPG_handle_t**.                                                                                            |
| ***i_level***        | Required. Log level of type **LOG4RPG_level_t**.                                                                                                        |

## Return Value

| Name                 | Description                                               |
|:---------------------|-----------------------------------------------------------|
| none                 |                                                           |

## Comments

none
