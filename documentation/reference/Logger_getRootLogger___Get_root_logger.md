# Logger_getRootLogger - Get root logger handle

Ermittelt den Root Logger and returns a value of type **LOG4RPG_hLogger_t**.

## Syntax

**Logger_getRootLogger**()

The syntax of **Logger_getRootLogger**-procedure uses the following parameters:

| Parameter            | Description                                               |
|:---------------------|:----------------------------------------------------------|
| none                 |                                                           |

## Return Value

| Name                 | Description                                               |
|:---------------------|-----------------------------------------------------------|
| ***hLogger***        | Handle of the root logger of type **LOG4RPG_hLogger_t**.  |

## Comments

none

LOG4RPG01
