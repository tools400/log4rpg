# Logger_addAppender - Add appender

Adds a given appender to a given logger.

## Syntax

**Logger_addAppender**(***i_hLogger***, ***i_pAppender***)

The syntax of **Logger_addAppender**-procedure uses the following parameters:

| Parameter            | Description                                                       |
|:---------------------|:------------------------------------------------------------------|
| ***i_hLogger***      | Required. Handle of the logger of type **LOG4RPG_hLogger_t**.     |
| ***i_pAppender***    | Required. Handle of the appender of type **LOG4RPG_pAppender_t**. |

## Return Value

| Name                 | Description                                               |
|:---------------------|-----------------------------------------------------------|
| none                 |                                                           |

## Comments

none
