# Logger_getName - Get logger name

Retrieves the name of a given logger and returns a value of type **LOG4RPG_loggerName_t**.

## Syntax

**Logger_getName**(***i_hLogger***)

The syntax of **Logger_getName**-procedure uses the following parameters:

| Parameter            | Description                                                   |
|:---------------------|:------------------------------------------------------------- |
| ***i_hLogger***      | Required. Handle of the logger of type **LOG4RPG_hLogger_t**. |

## Return Value

| Name                 | Description                                               |
|:---------------------|-----------------------------------------------------------|
| ***name***           | Name of the logger of type **LOG4RPG_loggerName_t**.      |

## Comments

none
