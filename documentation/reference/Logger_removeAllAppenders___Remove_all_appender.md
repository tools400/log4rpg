# Logger_removeAllAppenders - Remove all appenders

Removes all appenders from a given logger.

## Syntax

**Logger_removeAllAppenders**(***i_hLogger***)

The syntax of **Logger_removeAllAppenders**-procedure uses the following parameters:

| Parameter            | Description                                                        |
|:---------------------|:-------------------------------------------------------------------|
| ***i_hLogger***      | Required. Handle of the logger of type **LOG4RPG_handle_t**.       |

## Return Value

| Name                 | Description                                               |
|:---------------------|-----------------------------------------------------------|
| none                 |                                                           |

## Comments

none
