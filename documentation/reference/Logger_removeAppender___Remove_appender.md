# Logger_removeAppender - Remove appender (experimental)

Removes a given appender from a given logger.

## Syntax

**Logger_removeAppender**(***i_hLogger***, ***i_appName***)

The syntax of **Logger_removeAppender**-procedure uses the following parameters:

| Parameter            | Description                                                        |
|:---------------------|:-------------------------------------------------------------------|
| ***i_hLogger***      | Required. Handle of the logger of type **LOG4RPG_handle_t**.       |
| ***i_appName***      | Required. Name of the appender of type **LOG4RPG_appenderName_t**. |

## Return Value

| Name                 | Description                                               |
|:---------------------|-----------------------------------------------------------|
| none                 |                                                           |

## Comments

none
