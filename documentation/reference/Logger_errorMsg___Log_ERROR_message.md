# Logger_errorMsg - Log ERROR message

Appends an ERROR message to the log.

## Syntax

**Logger_errorMsg**(***i_hLogger***, ***i_msg***)

The syntax of **Logger_errorMsg**-procedure uses the following parameters:

| Parameter            | Description                                                   |
|:---------------------|:--------------------------------------------------------------|
| ***i_hLogger***      | Required. Handle of the logger of type **LOG4RPG_hLogger_t**. |
| ***i_msg***          | Required. Statement to log of type **LOG4RPG_*msg*_t**.       |

## Return Value

| Name                 | Description                                               |
|:---------------------|-----------------------------------------------------------|
| none                 |                                                           |

## Comments

none
