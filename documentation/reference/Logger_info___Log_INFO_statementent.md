# Logger_info - Log INFO statement

Appends a INFO statement to the log.

## Syntax

**Logger_info**(***i_hLogger***, ***i_text***)

The syntax of **Logger_info**-procedure uses the following parameters:

| Parameter            | Description                                                   |
|:---------------------|:--------------------------------------------------------------|
| ***i_hLogger***      | Required. Handle of the logger of type **LOG4RPG_hLogger_t**. |
| ***i_text***         | Required. Statement to log of type **LOG4RPG_text_t**.        |

## Return Value

| Name                 | Description                                               |
|:---------------------|-----------------------------------------------------------|
| none                 |                                                           |

## Comments

none
