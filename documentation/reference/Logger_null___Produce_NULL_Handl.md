# Logger_null - Produce NULL Handle

Produces a logger NULL handle and returns a value of type **LOG4RPG_hLogger_t**.

## Syntax

**Logger_null**()

The syntax of **Logger_null**-procedure uses the following parameters:

| Parameter            | Description                                               |
|:---------------------|-----------------------------------------------------------|
| none                 |                                                           |

## Return Value

| Name                 | Description                                               |
|:---------------------|-----------------------------------------------------------|
| ***hLogger***        | Logger NULL handle.                                       |

## Comments

none

## Module

LOG4RPG01
