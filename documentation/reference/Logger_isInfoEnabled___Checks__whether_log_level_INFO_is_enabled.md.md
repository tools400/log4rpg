# Logger_isInfoEnabled - Checks, whether log level INFO is enabled

Checks, whether or not log level INFO has been enabled.

## Syntax

**Logger_isInfoEnabled**(***i_hLogger***)

The syntax of **Logger_isInfoEnabled**-procedure uses the following parameters:

| Parameter            | Description                                                   |
|:---------------------|:--------------------------------------------------------------|
| ***i_hLogger***      | Required. Handle of the logger of type **LOG4RPG_hLogger_t**. |

## Return Value

| Name                 | Description                                                     |
|:---------------------|-----------------------------------------------------------------|
| ***isEnabled***      | Returns `*ON` if log level `INFO` is enabled, otherwise `*OFF`. |
