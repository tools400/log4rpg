# Logger_getInternalDebugOutput - Returns the output target of the internal debug log

Gets the current output target of the internal debug log and returns a value of type **LOG4RPG_debugOutput_t**.

## Syntax

**Logger_getInternalDebugOutput**(***i_hLogger***)

The syntax of **Logger_getInternalDebugOutput**-procedure uses the following parameters:

| Parameter            | Description                                                   |
|:---------------------|:--------------------------------------------------------------|
| ***i_hLogger***      | Required. Handle of the logger of type **LOG4RPG_hLogger_t**. |

## Return Value

| Name                 | Description                                                                |
|:---------------------|----------------------------------------------------------------------------|
| ***debugOutput***    | Output target of the internal debug lof of type **LOG4RPG_debugOutput_t**. |

## Comments

none
