# Logger_debugMsg - Log DEBUG message

Appends a DEBUG message to the log.

## Syntax

**Logger_debugMsg**(***i_hLogger***, ***i_msg***)

The syntax of **Logger_debugMsg**-procedure uses the following parameters:

| Parameter            | Description                                                   |
|:---------------------|:--------------------------------------------------------------|
| ***i_hLogger***      | Required. Handle of the logger of type **LOG4RPG_hLogger_t**. |
| ***i_msg***          | Required. Statement to log of type **LOG4RPG_msg_t**.         |

## Return Value

| Name                 | Description                                               |
|:---------------------|-----------------------------------------------------------|
| none                 |                                                           |

## Comments

none
