# Log-Level

Log4rpg supports 5 different log levels. The log levels are used to determine how detailed a log should be:

- DEBUG

- INFO

- WARN

- ERROR

- FATAL

Log level *DEBUG* causes a very detailed log while level *FATAL* results in a basic log. All other log level are used to produce logs between *DEBUG* and *FATAL*.
